# 🛒 Lista de Compras do Mês

**Organize suas compras de forma simples, rápida e sem esquecer nada.**

Uma lista de compras leve e intuitiva para adicionar produtos, separar por categoria e acompanhar o que já foi comprado — direto no navegador.

## ✨ O que você pode fazer

- ➕ **Adicionar produtos** com nome, quantidade e categoria.
- 🗂️ **Organizar a lista** em Mercearia, Hortifruti, Açougue e Laticínios, Limpeza, Higiene ou Outros.
- ✅ **Marcar itens comprados** e ver o progresso da sua lista.
- 🔎 **Filtrar itens** para visualizar todos, apenas os pendentes ou os já comprados.
- 🧹 **Limpar os comprados** quando quiser deixar a lista em dia.
- 💾 **Manter a lista salva no navegador** usando o armazenamento local.

## 🚀 Como usar

Não precisa instalar nada nem configurar ferramentas. Abra o arquivo `index.html` no navegador e comece a montar sua lista.

### Executar localmente

1. Baixe ou clone este repositório:

   ```bash
   git clone https://github.com/Kadu-Dias78/Compras.git
Abra a pasta do projeto.
Abra o arquivo index.html no seu navegador preferido.
Digite o nome do produto, escolha a quantidade e a categoria e clique em Adicionar.
🧭 Como funciona
Adicione cada produto com a quantidade desejada e uma categoria.
Marque a caixa ao lado do produto assim que ele for para o carrinho.
Use os filtros Todos, Pendentes e Comprados para encontrar o que precisa.
Se quiser, clique em Limpar comprados para remover da lista tudo o que já foi marcado.
💡 Os itens ficam salvos no localStorage do navegador. Eles continuam disponíveis no mesmo navegador e dispositivo, mas não são sincronizados entre dispositivos. Limpar os dados do navegador também pode apagar a lista.
